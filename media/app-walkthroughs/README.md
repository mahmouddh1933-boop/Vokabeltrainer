# شرح عملي للتطبيقين الأول والثاني

هذان الفيديوهان هما النسخة الجديدة المطلوبة: تسجيل مباشر لاستخدام التطبيق فقرة فقرة، مع فتح القوائم والبطاقات، والكتابة والاختيار، وتجربة الأدوات، وعرض التصحيح. لا تُستخدم صور «التطبيقات الأخرى» أو شرائح الفيديو التشجيعي السابق؛ يحظر سكربت التسجيل تحميل مسار `images/editions/`.

- [شرح البداية والحروف](../../downloads/Huroof-Start-Walkthrough-AR.mp4)
- [شرح العربية A1/A2](../../downloads/Huroof-A1-A2-Walkthrough-AR.mp4)

كل فيديو أقل من ست دقائق بدقة Full HD / H.264 / AAC. تظهر تعليمات عربية أثناء تنفيذ كل خطوة، مع تعليق عربي مأخوذ من الجمل المطابقة في دليل الاستخدام الموجود في المشروع. بعض الخطوات تستخدم شرحًا نصيًا فقط. تُضمَّن أمثلة النطق المحلية التي شُغّلت بنجاح أثناء التسجيل. التنفيذ داخل متصفح ببيانات مؤقتة ودون أي حساب حقيقي.

تسجّل ملفات `record-evidence.json` كل عملية وعنوان الصفحة وتوقيتها، وتسجّل `verification.json` مدة الملف وحجمه وبصمته وفحص فك ترميزه كاملًا. تتوفر ملفات ZIP مع النصوص والفصول وصورة الغلاف.

إعادة الإنتاج، بعد بناء التطبيقات وتشغيلها محليًا:

```sh
python3 tools/build-app-walkthroughs.py --app start --step preview
python3 tools/build-app-walkthroughs.py --app start --step record
python3 tools/build-app-walkthroughs.py --app start --step render
# ثم تكرار الأوامر مع --app a1-a2
```

المتطلبات: Python وNumPy وPlaywright وChromium وFFmpeg. لا تُستخدم خدمة صوت خارجية، ولا تُعدَّل بيانات التطبيقات أو ملفات حزمها.
