# شرح عملي — البداية والحروف

تسجيل مباشر لفتح أقسام التطبيق وتجربة أدواته. لا تُستخدم صور المعارض التشجيعية. تظهر التعليمات العربية في الشريط السفلي، مع تعليق صوتي عربي حيث تتوفر مقاطع مطابقة من دليل المشروع، وأمثلة صوتية محلية ناجحة من التطبيق. توجد بعض الخطوات بشرح نصي دون تعليق. تسجيل مؤقت دون حسابات حقيقية.

المدة: 200 ثانية، أقل من ست دقائق.

إعادة الإنتاج: `python3 tools/build-app-walkthroughs.py --app start --step preview` ثم `--step record` ثم `--step render`، بعد تشغيل حزمة التطبيقات محليًا على عنوان `--base-url`.
