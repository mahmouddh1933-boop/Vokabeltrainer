# فيديوهات التطبيقات — أول فيديوهين

- [البداية والحروف](../../downloads/Huroof-Start-Video-AR.mp4): الحروف، الكتابة، التدريب، الأصوات، القراءة والأنشطة.
- [العربية A1/A2](../../downloads/Huroof-A1-A2-Video-AR.mp4): المفردات، الاختبارات، الجمل، الوحدات، القواعد، تصريف الأفعال، القصص والمراجعة.

صور فعلية من أحدث لقطات التطبيقات في الإصدار `f7ba50b`، مع حركة تقريب هادئة، وعناوين عربية، وتعليق عربي صناعي، وترجمة نصية للكلام، وموسيقى آلية. حُفظت ألوان هوية الزيتون. التعليق مأخوذ من الجمل المطابقة للمزايا في الفيديوهات العربية الموجودة في المشروع. بعض مشاهد المزايا تستخدم نصوصًا توضيحية وموسيقى دون تعليق. لا يُستخدم تصوير لحسابات حقيقية، ولا يُغيَّر محتوى التطبيقات.

الصيغة: MP4 / H.264 / AAC، بدقة 1920×1080 و25 إطارًا في الثانية. كل فيديو متاح أيضًا في ZIP مع الترجمة النصية وصورة الغلاف ونص التعليق والفصول.

إعادة الإنتاج: `python3 tools/build-app-videos.py`، أو `--app start` و`--app a1-a2`. يحتاج FFmpeg وChromium وPlaywright وNumPy وfontTools. لا يتطلب خدمة تحويل نص إلى صوت أو اتصالًا خارجيًا. اللقطات ومصادر التعليق مسجلة في ملفات storyboard وcapture-evidence؛ نتائج التحقق في verification.
