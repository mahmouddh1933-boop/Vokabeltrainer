# تثبيت «حروف من الزيتون» كتطبيق PWA

PWA تتيح فتح الموقع من أيقونة مستقلة على الهاتف أو الحاسوب، مع حفظ الدروس محليًا للاستخدام دون اتصال. لا تحتاج إلى مشروع Firebase جديد أو خدمة مدفوعة إضافية؛ تبقى حدود الاستخدام والتخزين ونقل البيانات الخاصة باستضافتك سارية.

## تفعيل النسخة الجديدة على Firebase

1. حمّل حزمة **Huroof-Firebase.zip** الجديدة، ثم فكّ ضغطها.
2. افتح الطرفية داخل مجلد `Huroof-Firebase` الذي يحتوي `firebase.json` و`firebase-public`.
3. إذا لم تكن قد دخلت إلى Firebase CLI، نفّذ `firebase login`.
4. انشر ملفات الاستضافة:

```sh
firebase deploy --only hosting --project letters-from-olive
```

5. افتح `https://letters-from-olive.web.app` عبر الإنترنت، وسجّل الدخول. للتشغيل لاحقًا دون اتصال، اختر «تذكّرني» على جهازك الشخصي.
6. افتح فقرة **«تثبيت التطبيق والعمل دون إنترنت»** وانتظر ظهور أن الدروس النصية جاهزة. تستطيع متابعة التعلم أثناء تجهيز الملفات.

حزمة Firebase تتضمن المجلد الجاهز للنشر. لا تحتاج إلى Python عند نشر الحزمة، ولا إلى تغيير قواعد Firestore لهذا التحديث. الشيفرة نفسها لم تُنشر تلقائيًا على مشروع الإنتاج.

## أندرويد مع Chrome

1. افتح رابط الموقع في Chrome نفسه.
2. استخدم زر **«تثبيت التطبيق»** في الفقرة المذكورة، ثم وافق على التثبيت.
3. إذا عرض الزر تعليمات فقط، افتح قائمة **⋮** في Chrome واختر **«تثبيت التطبيق»** أو **«إضافة إلى الشاشة الرئيسية»** بحسب إصدار المتصفح.
4. افتح أيقونة **«حروف الزيتون»** من الشاشة الرئيسية.

في iPhone: افتح الرابط في Safari، ثم **مشاركة ← إضافة إلى الشاشة الرئيسية**. وقد تحتاج إلى تسجيل الدخول داخل النافذة المثبّتة أيضًا. في الحاسوب: استخدم Chrome أو Edge واختر رمز التثبيت بجانب شريط العنوان، أو زر التطبيق. قد لا يوفر المتصفح أو وضع التصفح الخاص خيار تثبيت مستقل.

## ما الذي يعمل دون إنترنت؟

- تُجهّز الصفحات النصية والبرامج والخطوط وبيانات الدروس في حزمة محلية ثابتة لكل إصدار. لا يشترط فتح كل درس منفردًا قبل قطع الاتصال، بعد اكتمال التجهيز.
- تُحفظ التسجيلات والصور عند طلبها أثناء اتصال الجهاز. الحد التلقائي **٥٠٠ ملف أو ٤٠ MiB**، أيهما يُبلغ أولًا؛ تُحذف الملفات الأقدم عند الحاجة. ليس كل صوت أو صورة في التطبيق منزّلًا مسبقًا.
- بعد التجهيز، استمع أثناء الاتصال إلى المقاطع التي تريد استعمالها دون إنترنت. صفحة التثبيت تعرض عدد ملفات الوسائط المحفوظة وحجمها، ويمكن مسحها دون حذف الإجابات والتقدم.
- الإجابات والمسودات محفوظة بطبقة التخزين القائمة. Firebase يحتاج إلى الإنترنت لإنشاء حساب أو دخول جديد أو استعادة كلمة السر أو نقل التقدم بين الأجهزة. جلسة Firebase المتذكَّرة مسبقًا تستطيع فتح المحتوى المحفوظ دون اتصال؛ لا يُتجاوز فحص الحساب.
- عند عودة الاتصال، تستأنف آلية المزامنة القائمة محاولاتها. لا يمكن لخدمة PWA وحدها تأكيد الحفظ على جهاز آخر أثناء انقطاع الشبكة.
- يمكن للمتصفح أو النظام إزالة ملفات الموقع عند نقص المساحة أو عند مسح بيانات التصفح؛ حالة التجهيز تعرض النقص، وزر «حفظ الدروس دون اتصال» يعيد تهيئتها بعد الاتصال.

## التحديثات

عند نشر إصدار جديد يُجهّز المتصفح ملفاته في الخلفية. لا يُفرض تحديث أثناء حل تمرين. يظهر زر **«تحديث التطبيق وإعادة فتح الصفحة»** عند جاهزية الإصدار؛ احفظ إجاباتك ثم اضغطه. إغلاق جميع نوافذ التطبيق وفتحه لاحقًا يسمح أيضًا باعتماد الإصدار المنتظر. الصفحات المفتوحة في تبويبات أخرى لا تُجبر على إعادة تحميل مفاجئة.

زر **«البحث عن تحديث»** يفحص الإصدار عند الاتصال. يُحتفظ بالإصدار السابق مؤقتًا لدعم ملفات التبويبات التي لم تُعد فتحها. إذا انقطع تنزيل التحديث أو اختلفت بصمة ملف، يبقى الإصدار الكامل السابق فعالًا.

## ZIP ونسخة العرض

- فتح `index.html` من القرص يبقى مدعومًا كالسابق، لكنه لا يثبت PWA؛ يلزم HTTPS أو localhost. يمكن رفع المجلد الكامل المستخرج على استضافة HTTPS أخرى.
- حزمة ZIP الكاملة، وحزمة Firebase، ونسخة Demo تولّد كل منها عامل خدمة مطابقًا لملفاتها الفعلية؛ الصفحات المضمَّنة في ZIP تختلف عن صفحات المصدر وصفحات Firebase المحمية.
- نسخة Demo لها اسم تثبيت مميز وتحتوي ملفاتها المختارة فقط. التسجيل والدخول والمزامنة غير موجودة فيها.
- المسارات نسبية، ولذلك يعمل التثبيت في جذر النطاق أو في مجلد فرعي. لكل مسار تطبيق مخزونه الخاص.

## ملفات التنفيذ والتحقق

`manifest.webmanifest` هو ملف تعريف التثبيت. `images/pwa/` يحتوي أيقونات PNG بقياسات 192 و512 و180، وأيقونة maskable ذات مساحة آمنة. `js/pwa.js` يدير التثبيت والحالة والتحديث؛ `css/pwa.css` ينسّق الفقرة؛ `offline.html` صفحة رجوع عند طلب رابط غير محفوظ.

`tools/build-pwa.py` يولّد `pwa-worker.js` من بصمات الملفات. الحزمة الأساسية تُتحقق ببصمات SHA-256 قبل التفعيل. الكاش يقتصر على قائمة معلومة من ملفات التعليم العامة؛ لا تُخزّن كلمات السر أو رموز الدخول أو استجابات Firebase أو طلبات API، ولا يُستخدم حساب مخزّن يدويًا لتجاوز Firebase Auth. طلبات الصوت الجزئية Range تُخدم من الملف الكامل، لدعم التشغيل والتنقل داخل التسجيل دون اتصال.

يُولد العامل تلقائيًا في أدوات بناء ZIP وFirebase وDemo. عند تعديل الملفات وبناء نسخة جديدة:

```sh
python tools/build-download.py
python tools/build-hosting.py --archive
python tools/build-demo.py --directory /tmp/huroof-pwa-demo-new
node --test tests/*.test.js
```

اختبارات المتصفح:

```sh
python tests/pwa-smoke.py --base-url http://127.0.0.1:8070
python tests/pwa-update-smoke.py
python tests/pwa-auth-smoke.py
```

الاختبار الأول يراجع شروط التثبيت في Chromium بملف متصفح دائم، والدروس والملفات الأساسية والصوت بعد قطع الشبكة، وRange، والمسودات، وحدود نطاق التخزين، ومسح الوسائط وإصلاح الحزمة، والواجهتين العربية والألمانية. الثاني يختبر تحديثًا منتظرًا في مجلد فرعي مع تبويبين، وحفظ الإصدار السابق عند فشل تنزيل إصدار. الثالث يستخدم Firebase Auth Emulator على 9099 وHosting Emulator على 5000 فقط، ويختبر الإغلاق الكامل ثم الفتح دون إنترنت، والخروج دون اتصال، وفصل تقدم حسابين. لا ينشئ حسابات إنتاجية. اختبار iPhone/Android مادي لم يُجرَ داخل البيئة.
