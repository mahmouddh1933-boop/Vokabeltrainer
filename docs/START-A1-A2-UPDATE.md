# تحديث Huroof-Start وHuroof A1-A2

هذا التحديث محصور في التطبيقين المذكورين. لم تتغير حزم B1-B2 أو الكتب أو حزمة الإعداد المشتركة، ولا صور معاينتها.

## Huroof-Start

- تبدأ أنشطة «تدريبات على القراءة» بإجابات فارغة عند الدخول أو إعادة تحميل الصفحة أو العودة إليها من ذاكرة المتصفح. يُمسح أيضًا التلوين وترتيب الأحداث والرسم والكتابة وقائمة المراجعة الخاصة بالمحاولة.
- تبقى علامة الإنجاز السابقة محفوظة في سجل التقدم. تغيير لغة الواجهة أثناء المحاولة لا يمحو الإجابات.
- يتضمن باب «مفاتيح الكلمات» نشاط «اختبر نفسك»: خمسة أسئلة من خمسة أنشطة مختلفة، مسحوبة من بنك أسئلة الباب كله. زر الإعادة يستبعد أسئلة الجولة السابقة، وزر الرجوع يعيد المتعلم إلى الباب.

## Huroof A1-A2

- تعرض واجهة الوحدات «وحدات المستوى الأول» و«وحدات المستوى الثاني»، بست وحدات لكل مستوى. تبقى المهارات السبعة داخل الوحدة.
- أُدرجت ملفات الصوت الـ٤٨ للوحدات في الحزمة؛ كانت الحزمة السابقة تفتقد ملفات الحوارين والقراءة. تشغّل المفردات ملفاتها المحلية في مشغّل الوحدة نفسه.
- أُضيف الاستماع إلى شرح قاعدة الوحدة مع زر إيقاف. يستخدم هذا الشرح صوت الجهاز العربي، مع بديل النطق عبر الإنترنت عند تعذره؛ لا يُقدَّم بوصفه تسجيلًا بشريًا أو تسجيلًا محليًا مضمون العمل دون اتصال.
- أُضيف درس «أسماء الاستفهام» ودرس «المفعول فيه: ظرف الزمان وظرف المكان»، بشرح وأمثلة مشكولة و٢٠ سؤالًا مع تصحيح وتفسير لكل درس. تميّز الأمثلة بين الظرف والمبتدأ والاسم المجرور، وبين أسماء الاستفهام وحرفي الاستفهام.
- أصبح إجمالي قواعد هذه النسخة ١٩ درسًا و٢٤٤ سؤالًا. الدرسَان إضافتان خاصتان بهذه النسخة؛ لم يُعدَّل محتوى قواعد B1-B2.
- يوجد زر رجوع في صفحات التعلم، ويتتبع الانتقالات بين الصفحات وأجزاء الوحدة داخل التطبيق نفسه. عند الدخول المباشر يستخدم وجهة رجوع مناسبة.

## التحقق

- نجحت ١٢ مجموعة فحص آلي للمحتوى واختيار الأسئلة وصوت أنشطة القراءة وملفات الوحدات.
- نجح اختبار المتصفح على النسخة المبنية: مسح المحاولة مع حفظ الإنجاز، الاختبار العشوائي وإعادته، تشغيل MP3 فعلي للحوارين والقراءة والمفردات في A1 وA2، قراءة شرح القاعدة باستخدام محرك صوت اختباري مضبوط، حل أسئلة الدرسين الأربعين، الرجوع، وعرض عربي وألماني بعروض ٣٢٠–١٤٤٠ بكسل.
- فُحصت سلامة ملفي ZIP وبصمات جميع ملفات PWA فيهما، وتطابقت بصمات الحزم الثلاث غير المعدلة قبل البناء وبعده.
- لم يُجرَ اختبار سمعي على هاتف حقيقي، ولم يُنشر تحديث إلى Firebase أو تُعدَّل إعدادات الحسابات.

لإعادة بناء هاتين النسختين فقط، مع إبقاء النسخ الأخرى وحزمة الإعداد:

```sh
python3 tools/build-suite.py --directory /tmp/huroof-four-apps --archives --editions start a1-a2
node --test tests/start-a1-update.test.js tests/reading-workshop.test.js tests/reading-workshop-audio.test.js tests/skills.test.js
HUROOF_TEST_BASE=http://127.0.0.1:8090 python3 tests/start-a1-update-smoke.py
```

يتطلب اختبار المتصفح تشغيل خادم محلي للمجلد المبني، وPlaywright وChromium. عند رفع التحديث، تُستبدل محتويات مجلدي `start` و`a1-a2` فقط بعد فك الضغط، مع إبقاء بقية التطبيقات وإعدادات Firebase.
