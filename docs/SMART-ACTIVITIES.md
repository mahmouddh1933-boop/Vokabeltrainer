# الأنشطة التفاعلية: التصنيف والتوصيل

المكان الرئيسي: **الكتب والاختبارات ← كتاب ٣**، ثم اختيار:

- **أصنف الكلمات: اسم وفعل وحرف** (`youth-training-two.html#c-p24-b2`): بنك كلمات يُسحب إلى ثلاثة مستطيلات، أو اختيار كلمة ثم مستطيل بالنقر/لوحة المفاتيح، وجدول يتابع اختيارات المتعلّم.
- **أصل الكلمة بضدها** (`youth-training-two.html#c-p20-b1`): سحب بين طرفين بخطوط ملوّنة تظهر أثناء الحركة وتثبت عند الإفلات. الأرقام تميز المطابقات أيضًا.

السحب يعمل بالماوس واللمس. يمكن تغيير الاختيار قبل التصحيح، وإرجاع الكلمة إلى البنك بالسحب أو زر الإرجاع أو Delete بعد تحديدها. Escape يلغي السحب أو التحديد. عند تغيير حجم الشاشة يُعاد ضبط الخطوط. النقر المتتابع على الطرفين وEnter/Space يوفران بديلًا عن السحب.

في التدريب يُصحَّح النشاط بعد توزيع جميع عناصره. يعرض الجدول الاختيار ونتيجته والتفسير المتاح في السؤال. «أعيد غير الصحيح فقط» يحتفظ بالإجابات الصحيحة ويعيد الأخطاء إلى المحاولة. التقدم والإجابات والمسودات تبقى في مفاتيح التخزين القديمة الخاصة بكل كتاب وحساب.

داخل الاختبارات تُحفظ الاختيارات كمسودة، ولا تُكشف صحتها إلا بعد تسليم الاختبار كله. تبقى معرفات الأسئلة وقيم الإجابات واحتساب الدرجات وأسئلة الطباعة والملفات الأصلية دون تغيير. لا تُرسل إجابات المتعلّم إلى خدمة ذكاء اصطناعي، ولا تُصحَّح الأسئلة المفتوحة آليًا.

## الأنشطة المشابهة التي حُسّنت

**٦٩ نشاطًا/قسمًا** تضم ٥٢٤ سؤالًا قائمًا، دون إضافة درجات جديدة:

- ١٤ نشاطًا في كتاب ٣: الفصول، الضمائر، المفرد والمثنى والجمع، أنواع الجمل، أزمنة الأفعال، أقسام الكلمة، الأضداد، المفرد والجمع، تراكيب الرياضة، الأماكن، الاستفهام وحروف الجر.
- ٦ أنشطة مفردات في وحدات كتاب ٢: توصيل التعريف بالكلمة.
- تصنيف الكلمات حسب الحرف الأول في دروس كتاب ١ الثمانية والعشرين.
- ٢١ قسمًا في الاختبارات الأصلية والنماذج المشابهة: أقسام الكلمة، أنواع الجمل، الأضداد وبعض مطابقات المفردات والتراكيب.

الجرد التفصيلي موجود في `data/smart-activities.json` تحت `inventory`، مع الصفحة ومعرف النشاط أو رقم القسم. لم تُحوّل أسئلة السماع أو الصور أو الكتابة الحرة إلى واجهة لا تناسبها.

## الصيانة والفحص

المكوّن المشترك: `js/smart-activities.js` و`css/smart-activities.css`. خريطة الأنشطة تُبنى من الأسئلة الأصلية بقائمة تحويلات صريحة ومدروسة:

```sh
node tools/build-smart-activities.cjs
node --test tests/smart-activities.test.js
python3 tools/build-suite.py --directory /tmp/huroof-smart-suite
python3 -m http.server 8098 --bind 127.0.0.1 --directory /tmp/huroof-smart-suite
```

من نافذة أخرى:

```sh
python3 tests/smart-activities-smoke.py --base-url http://127.0.0.1:8098/books
```

يفحص المتصفح السحب الحقيقي بالماوس، وأحداث اللمس الفعلية، والخط المؤقت أثناء السحب، وإلغاء اللمس، والنقر ولوحة المفاتيح، وإعادة الرسم بعد تغيير العرض، وإعادة الأخطاء فقط، والتخزين بعد التحديث، والعربية والألمانية، وجميع الأنشطة المحوّلة ودرجات الاختبارات. لم يُستخدم هاتف فعلي؛ فحص اللمس عبر Chromium.
