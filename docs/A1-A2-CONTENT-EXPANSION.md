# تحديث المستوى الأول والمستوى الثاني

التعديل خاص بحزمة `Huroof-A1-A2.zip`. لم تتغير حزم البداية أو B1-B2 أو الكتب أو الإعداد المشترك، ولا صور التطبيقات الأخرى.

## الواجهة

- حُذف شريط «الأصوات المتشابهة / تكوين الجمل / قصص قصيرة» من صفحات التدريب في هذه النسخة.
- تُعرض تسميتا «المستوى الأول» و«المستوى الثاني» بدل الرمزين في الواجهة العربية، وStufe 1 وStufe 2 في الألمانية. تبقى معرّفات المستويات الداخلية وروابط القوائم ومفاتيح التقدم كما هي لحفظ التوافق مع بيانات المتعلم.
- ترتيب القائمة: نظرة عامة، مفردات المستوى الأول والثاني، تكوين جمل، قصص قصيرة، المهارات والوحدات، القواعد والإملاء، مراجعة المفردات، تقدّمي، التطبيقات الأخرى. تبقى لوحة الإدارة متاحة للمدير.
- يوجد تصريف الأفعال داخل القواعد والإملاء؛ اختبارات المفردات متاحة من قسم المفردات، دون عنصر مستقل في القائمة الجانبية.

## القصص

أصبحت المكتبة ٢٤ قصة، ١٢ لكل مستوى. أُضيفت ١٨ قصة إلى القصص الست السابقة، دون تغيير معرّفات القصص القديمة أو سجلاتها. لكل قصة ست جمل عربية وترجمتها الألمانية وأربع مفردات وأربعة أسئلة فهم تربط التصحيح بدليل من النص؛ الإجمالي ١٤٤ جملة و٩٦ سؤالًا.

تتناول قصص المستوى الأول الأسرة والحيوان الأليف والحديقة والملابس والمطر والطبيبة والأصدقاء والجدة والمخبز والقلم المفقود. تتدرج قصص المستوى الثاني إلى تغيير المواعيد والسفر والأمانة والعمل الجماعي والجيران وإصلاح عطل والاستعارة والمقارنة قبل الشراء. يعتمد استماع الجمل الجديدة على مسار النطق الموجود في التطبيق؛ لم تُنتج تسجيلات بشرية جديدة.

## تصريف الأفعال

تضم هذه النسخة الآن جميع الأفعال الـ٥١ السابقة، إضافة إلى ١٠٠ فعل جديد مختلف، أي ١٥١ فعلًا. لكل فعل جداول الماضي والمضارع والأمر، والنفي بما ولا ولم ولن والنهي، مع تصنيف بحسب الجذر وعدد حروف صيغة الماضي:

| التصنيف | العدد |

| صحيح مضاعف | ٧ |
| معتل مثال | ٩ |
| معتل أجوف | ٨ |
| معتل ناقص | ٨ |

| عدد حروف الماضي | العدد |
| --- | ---: |
| ثلاثية | ٩٥ |

يُحسب الحرف المشدد بحرفين في هذا التصنيف. أُنشئت الصيغ الجديدة من جذوع محددة، مع جداول صريحة للأفعال التي تحتاج تغييرات، وللنصب والجزم. تشمل المراجعة حذف حرف العلة، وردّه مع بعض اللواحق، وفك الإدغام، وإدغام النون، وهمزتي المتكلم والمد، وحذف نون الأفعال الخمسة مع الحفاظ على نون النسوة. مصدر التوليد القابل لإعادة الإنتاج هو `tools/build-a1-a2-verbs.py`؛ لا يخمّن المتصفح الجذور أو الأبواب من كتابة الكلمة.

لم تُحذف نسخ الأفعال الموجودة في تطبيق B1-B2، التزامًا بطلب عدم تعديل التطبيقات الأخرى؛ أصبحت جميعها متاحة هنا أيضًا.

## قواعد الوحدات

يفتح «شرح القاعدة كاملًا» درس الوحدة نفسه ويعرض روابط جميع قواعدها، مع الانتقال مباشرة إلى منطقة الشرح وزر للعودة إلى الوحدة. في الوحدة الأولى يظهر درسا «الضمائر» و«أسماء الاستفهام» معًا كخيارين داخل سياق الوحدة.

| الوحدة | الدروس المرتبطة |
| --- | --- |
| الأولى من المستوى الأول | الضمائر، أسماء الاستفهام |
| الثانية | الأفعال الأساسية، الواو والفاء وثم |
| الثالثة | المذكر والمؤنث، النعت |
| الرابعة | الفاعل والمفعول به |
| الخامسة | حروف الجر، ظرف الزمان والمكان |
| السادسة | الواو والفاء وثم |
| الأولى من المستوى الثاني | إعراب المضارع والنفي بلم |
| الثانية والثالثة | السبب والنتيجة والرأي |
| الرابعة | الأمر، ترتيب الخطوات |
| الخامسة | المقارنة بأفعل من |
| السادسة | الماضي والمستقبل في السياق |

أُضيفت شروح الربط والسبب والنتيجة والمقارنة والماضي والمستقبل، وأُدرج درسا إعراب المضارع وبناء الأمر محليًا. صار مجموع قواعد هذه النسخة ٢٥ درسًا و٣١٦ سؤالًا.

## التحقق وإعادة البناء

نجحت اختبارات الصيغ المرجعية المستقلة وسلامة المحتوى. اختبر المتصفح القصص الأربع والعشرين وأسئلتها الستة والتسعين، واختيار الأفعال الـ١٥١ وجداولها وتصنيفاتها، وروابط الوحدات الاثنتي عشرة والعودة منها، وترتيب القائمة وإخفاء الشريط والتسميات وعرض العربية والألمانية بين ٣٢٠ و١٤٤٠ بكسل. فُحصت حزمة ZIP وبصمات ملفات PWA ووجود تسجيلات الوحدات الـ٤٨، وتطابقت بصمات الحزم الأخرى قبل البناء وبعده. لم يُختبر هاتف فعلي، ولم يُنشر تحديث إلى Firebase.

```sh
python3 tools/build-a1-a2-verbs.py
python3 tools/build-suite.py --directory /tmp/huroof-four-apps --archives --editions a1-a2
node --test tests/a1-a2-expansion.test.js tests/verbs.test.js tests/verb-negation.test.js tests/skills.test.js
# شغّل خادمًا للمجلد المبني أولًا.
HUROOF_TEST_BASE=http://127.0.0.1:8092 python3 tests/a1-a2-expansion-smoke.py
```

عند رفع النسخة يُستبدل محتوى مجلد `a1-a2` فقط بعد فك الضغط، وتُترك المجلدات الأخرى وإعدادات Firebase كما هي.
