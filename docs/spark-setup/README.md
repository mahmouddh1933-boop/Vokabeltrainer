# دليل إعداد Firebase Spark بالصور

- افتح `index.html` لعرض تسع خطوات مع أزرار نسخ الأوامر. أمثلة الأوامر موجهة إلى Windows Command Prompt؛ تبقى أوامر Firebase نفسها في الأنظمة الأخرى.
- في حزمة ZIP يوجد ملف PDF والصور التسع والدليل النصي. الروابط إلى تنزيل التطبيق وFirebase وNode.js وJava تحتاج إلى الإنترنت.
- الصور ١–٨ مخططات توضيحية وليست لقطات من حساب Firebase الخاص بك. قد تتغير أماكن القوائم حسب لغة الواجهة وتحديثاتها. تبقى أسماء المشروع والمجموعة والحقل والأوامر هي المقصودة.
- الصورة ٩ تتضمن لقطة فعلية من لوحة إدارة التطبيق، التُقطت في المحاكي المحلي ببيانات تجريبية. لم يُفتح حساب الإنتاج أو يُنشر أي تغيير لإعداد هذا الدليل.
- استخدم خطة Spark دون وسيلة دفع. الحصص المجانية محدودة. يجب نجاح اختبار قواعد Firestore الرسمي قبل النشر؛ تنزيل المحاكي كان محجوبًا في بيئة التجهيز.
- حد الجهازين داخل التطبيق إرشادي؛ تعطيل الإيميل هو ما يحجب وصول الحساب إلى بياناته وفق القواعد. إنشاء حساب Authentication وحده لا يمنحه الدخول إلى الدروس.
- إذا سبق تشغيل وظائف مدفوعة أو خطة Blaze، راجع خطوات الانتقال في `ADMIN-SETUP-AR.md`؛ نشر النسخة المجانية لا يحذف الخدمات القديمة تلقائيًا.

لإعادة إنشاء الرسومات والملفات من المصدر، في بيئة تحتوي Python وPlaywright وChromium:

```sh
python tools/build-spark-guide.py --render
```

ملفات الخطوط مصحوبة بتراخيصها، وهي مضمنة أيضًا داخل HTML حتى لا يحتاج العرض إلى تنزيل خط خارجي.
