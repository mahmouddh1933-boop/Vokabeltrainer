# وحدات B1 وB2

تحتوي نسخة `Huroof-B1-B2` على ٤٠ وحدة: ٢٠ لكل مستوى، مبنية على ملف المستخدم `حروف_من_الزيتون_40_وحدة.html`. احتُفظ بنصوص القراءة الطويلة وعناوين الوحدات وأسئلة النقاش ومهام الكتابة. لم يُشغّل كود الملف المرفق داخل التطبيق؛ نُقلت بياناته إلى نموذج التطبيق، مع تصحيح أمثلة المفردات وإضافة مفردات خاصة بالموضوع وقواعد تطبيقية وتقارير استماع.

كل وحدة تضم ستة أقسام:

- القراءة: ٢٠٠–٣٥٠ كلمة في B1 و٣٥٠–٦٠٠ في B2، مع أسئلة فهم وتصحيح وإعادة المحاولة.
- المفردات: ثمانية مداخل لكل وحدة، منها مفردات خاصة بموضوعها ومفردات عمل مشتركة، ومعانٍ ألمانية وأمثلة مترجمة وتمارين.
- القواعد: شرح مرتبط بالوحدة، ومثال وتدريب، ورابط إلى الدرس الموسع عندما يكون في النسخة نفسها.
- الاستماع: تقرير عربي محلي وأسئلة فهم، مع نص قابل للفتح وسرعات تشغيل مختلفة.
- المحادثة: أسئلة للنقاش والتعليل وملاحظات محفوظة وتقييم ذاتي.
- الكتابة: قصة أو رسالة في B1 ومقال حجاجي في B2، مع عداد كلمات ومسودة محفوظة وقائمة مراجعة. لا يوجد تصحيح آلي للنصوص الحرة أو تقييم آلي للنطق.

تحفظ الإجابات والتقدم والمسودات تحت `learningStats.advancedUnitsV1` باستخدام آلية التخزين الحالية، منفصلة لكل وحدة ونسخة وحساب. إتمام الأقسام المغلقة يتطلب إجابات صحيحة كاملة؛ وإتمام المحادثة والكتابة يقرره المتعلم بعد المراجعة. لا يثبت الاختبار المحلي اتصال حساب Firebase حقيقي.

الأفعال الـ٢٥١ وقواعد تصريفها وفلاتر العائلات مطابقة لنسخة A1/A2. أزيل رابط اختبارات المفردات من القائمة الجانبية في B1/B2، وتظل الاختبارات متاحة من أنشطة المفردات. درس `passive-voice` يشرح المبني للمجهول ونائب الفاعل في الصحيح والمضعّف والأجوف والناقص؛ ويتوسع `active-participle` في اسم الفاعل والإعلال وإعراب المنقوص.

الشعار الجديد مأخوذ حرفيًا من الصورة المضمّنة في الملف المرفق، وهي مطابقة للصورة التي أرسلها المستخدم. الصورة الأصلية في `images/brand/olive-logo.png`، والمرجع المركزي `olive-symbol.svg` يعرضها دون تعديل بصري. حُدّثت أيقونات التثبيت أيضًا. تستخدم بقية النسخ المرجع المركزي نفسه عند إعادة بنائها؛ أُعيد إصدار أرشيفات التطبيقات الأربعة بعد تحسين الواجهة المشتركة.

## الملفات وإعادة البناء

البيانات الأصلية المعتمدة: `data/b1-b2-units.json`، وإضافات القواعد: `data/b1-b2-grammar.json`. بعد تعديل بيانات الوحدات:

```sh
python3 tools/build-b1-b2-data.py
python3 tools/build-suite.py --directory /tmp/huroof-four-apps
python3 tools/build-suite.py --directory /tmp/huroof-four-apps --editions b1-b2 --archives
```

الأمر الأخير يحدّث `downloads/Huroof-B1-B2.zip` دون إعادة كتابة أرشيفات التطبيقات الثلاثة الأخرى. ولـFirebase Hosting استخدم الأمر الحالي للمستودع:

```sh
python3 tools/build-suite.py --directory firebase-public --hosting
```

الاستماع مسجّل بصوت عربي اصطناعي من eSpeak-NG، ويعمل دون شبكة بعد تنزيل الملفات. يتضمن `audio/b1-b2-manifest.json` النصوص والمدد وبصمات SHA-256 للتسجيلات الأربعين. لإعادة توليد الصوت عند تغيير نصوص الاستماع، تحتاج Node وFFmpeg:

```sh
npm --cache /tmp/huroof-npm-cache install --prefix /tmp/huroof-tts --no-audit --no-fund @echogarden/espeak-ng-emscripten@0.3.5
node tools/generate-b1-b2-audio.mjs /tmp/huroof-tts/node_modules/@echogarden/espeak-ng-emscripten/espeak-ng.js
```

هذا مولّد تطوير فقط، ولا يحتاج تشغيل التطبيق إلى تثبيت حزم أو الاتصال بخدمة نطق. حزمة المحرك منشورة بترخيص GPL-3.0 في مستودع [Echogarden](https://github.com/echogarden-project/espeak-ng-emscripten)، ولا يُضمّن المحرك نفسه في التطبيق.

## الفحص

بعد البناء شغّل خادمًا من مجلد الإخراج:

```sh
python3 -m http.server 8090 --bind 127.0.0.1 --directory /tmp/huroof-four-apps
```

ثم من جذر المستودع:

```sh
node --test tests/b1-b2-expansion.test.js
python3 tests/b1-b2-expansion-smoke.py
python3 tests/b1-b2-package-smoke.py
```

يفحص اختبار المتصفح الأقسام الـ٢٤٠، والإجابات الخاطئة وتصحيحها، وتشغيل التسجيلات الأربعين، واستقلال المسودات وحفظها بعد التحديث، والواجهة العربية والألمانية وعروض الهاتف. يفحص اختبار ZIP بصمات الملفات وتشغيل النسخة المحمولة مع حظر طلبات JavaScript وCSS المنفصلة، والصوت المحلي والمسودات والتصريف والدرس الجديد. لم يُختبر جهاز هاتف فعلي أو حساب Firebase حي.
